Datenschutzerklärung

Stand: 7. November 2026

1. Worum es geht

Hermes ist ein persönlicher KI-Agent, der lokal auf dem Computer des Nutzers läuft. Diese Erklärung beschreibt, wie Hermes mit Daten umgeht, insbesondere mit Daten aus dem Google-Konto, die der Nutzer per Google-Anmeldung (OAuth) freigibt.

2. Verarbeitete Daten

Hermes greift nur auf die Google-Daten zu, für die der Nutzer auf dem Zustimmungsbildschirm von Google ausdrücklich seine Einwilligung erteilt hat. Der Zugriff erfolgt ausschließlich, um die vom Nutzer angeforderten Aufgaben auszuführen.

3. Speicherung und Weitergabe

Alle Daten und Zugriffstoken werden ausschließlich lokal auf dem Rechner des Nutzers verarbeitet und gespeichert. Es gibt keinen Hermes-Server, auf den Daten übertragen werden. Hermes verkauft keine Daten, gibt sie nicht an Dritte weiter und nutzt sie nicht für Werbung.

4. Google API Limited Use

Die Nutzung und Übertragung von Informationen, die Hermes aus Google-APIs erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

5. Widerruf und Löschung

Der Nutzer kann den Zugriff jederzeit in seinem Google-Konto unter myaccount.google.com/permissions widerrufen. Da alle Daten lokal liegen, können sie durch Löschen der Hermes-Daten auf dem eigenen Rechner entfernt werden.

Privacy Policy

Last updated: November 7, 2026

Overview. Hermes is a personal AI agent that runs locally on the user's own computer. It accesses Google account data only where the user has explicitly granted consent through Google's OAuth consent screen, and only to carry out tasks the user requests.

Storage and sharing. All data and access tokens are processed and stored only on the user's own computer. There is no Hermes server that receives data. Hermes does not sell data, share it with third parties, or use it for advertising.

Limited Use. Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion. Users can revoke access at any time at myaccount.google.com/permissions. Because all data is local, it can be deleted by removing Hermes' data from the user's computer.
